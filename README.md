# 🍓 Fresh Smoothie Bar (ร้านน้ำปั่นผลไม้สด)

เว็บไซต์ร้านน้ำปั่นผลไม้สดออนไลน์ ออกแบบมาให้ใช้งานง่าย ดีไซน์น่ารัก สดใส รองรับทั้งมือถือและคอมพิวเตอร์ (Responsive Design)

---

## ✨ จุดเด่นของระบบ
- 🍉 **เมนูน้ำปั่นหลากหลาย**: จัดหมวดหมู่เมนูผลไม้สด, โยเกิร์ตสมูทตี้ และเมนูสุขภาพพิเศษ
- 🧋 **ปรับแต่งแก้วโปรด**: เลือกระดับความหวาน (0%, 25%, 50%, 100%) และเพิ่มท็อปปิ้ง (บุกคอลลาเจน, เมล็ดเจีย, ว่านหางจระเข้, กราโนล่า)
- 🛒 **ระบบตะกร้าสินค้า (Cart & Checkout)**: คำนวณราคาแบบเรียลไทม์ เพิ่ม/ลดจำนวน และสรุปใบสั่งซื้อ
- 📱 **Mobile-First Responsive**: ใช้งานบนสมาร์ทโฟนได้อย่างลื่นไหล
- 🧪 **Unit Test & CI**: มีระบบทดสอบตรรกะการคำนวณและ GitHub Actions Workflow

---

## 🚀 วิธีเปิดใช้งาน
1. **เปิดผ่านเบราว์เซอร์**: ดับเบิลคลิกเปิดไฟล์ `index.html` ได้ทันที หรือใช้งานผ่าน Live Server
2. **รันบน GitHub Pages**:
   - ไปที่แท็บ **Settings** > **Pages**
   - ในส่วน **Branch** เลือก `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
   - รอระบบสร้างลิงก์เว็บไซต์พร้อมใช้งานออนไลน์ได้ทันที

---

## 🧪 การทดสอบ (Tests)
รัน Unit Tests สำหรับคำนวณราคาและโครงสร้างข้อมูลเมนู:
```bash
npm test
```
